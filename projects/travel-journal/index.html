AI Travel Journal Assistant

Apr 2025 – Aug 2025 • TUM Connected Mobility Lab

An AI-powered travel journal application that automatically organizes photos, extracts metadata, enriches location context, and builds interactive travel timelines for users.

Technical Highlights

  • Full-Stack Architecture: Built with a React frontend, a FastAPI Python backend, and a PostgreSQL database with Dockerized deployment workflows.
  • GenAI Image Microservice: Led the development of a generative AI microservice for automated image analysis, vision-based scene interpretation, and metadata enrichment.
  • Automated Timelines: Automatically generates chronological travel timelines and enables personal information search across photo collections based on visual content and location data.
  • DevOps Lifecycle: Configured CI/CD workflows, unit/integration testing, and containerized development setups for team collaboration (Team W4).
