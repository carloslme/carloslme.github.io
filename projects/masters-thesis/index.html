Special Feature • Master's Thesis

KG Construction and Retrieval for LLM-Based Test Scenario Generation from Automotive Regulations

Implementation underway

Institution: Technical University of Munich (TUM)

Chair: Chair of Robotics, AI and Real-Time Systems (Prof. Alois Knoll)

Advisor: André Schamschurko

Overview

This thesis investigates a structured Knowledge Graph retrieval layer to improve Retrieval-Augmented Generation (RAG) for automated vehicle testing. By integrating Knowledge Graphs with LLMs, the research aims to enhance the automated generation of test scenarios directly from complex automotive regulatory standards.

The domain focus is generating executable test scenarios (speed / load condition / post-condition tuples) derived from UN Regulation 152 (Advanced Emergency Braking Systems for M1 and N1 vehicles).

Research Objectives and Methodology

  • Knowledge Graph Retrieval Layer: Design and evaluate a structured Knowledge Graph retrieval layer that captures structural dependencies and regulatory semantics from automotive regulations.
  • Test Scenario Generation: Improve LLM-driven generation of structured test scenarios (speed / load condition / post-condition tuples).
  • Benchmarking Framework: Benchmark performance against three systems: RegulaRAG, LightRAG, and HippoRAG 2.
  • Evaluation Metrics: Measure retrieval and generation performance using Precision, Recall, and F1 score, alongside scenario generation success and failure rates.
